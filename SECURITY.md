# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within AMEVA Runtime, please send an email to:
`dev@ameva.org` or open a private advisory at https://github.com/uno-km/ameva-runtime/security/advisories.

Please include:
- A description of the issue and potential impact
- Detailed steps to reproduce or proof of concept
- Affected platform and architecture (e.g. Android 15 Termux aarch64, Windows x64)

We will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
