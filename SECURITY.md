# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.6.x   | :white_check_mark: |
| < 2.6.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within AMEVA Runtime, please report it via private vulnerability reporting:
- GitHub Security Advisory: https://github.com/uno-km/ameva-runtime/security/advisories
- Direct maintainer contact: zhfldk014745@naver.com

Please include:
- A description of the issue and potential security impact
- Detailed reproduction steps or proof-of-concept
- Affected environment (e.g. Android 15 Termux aarch64, Windows x64)

We aim to acknowledge receipt of vulnerability reports within 48 to 72 hours and coordinate remediation prior to public disclosure.
